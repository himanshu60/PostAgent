How PostAgent works

PostAgent is your AI LinkedIn content studio. It researches what's trending in tech, writes on-brand posts with matching visuals, and publishes them to your own LinkedIn account on a schedule you control.

The 3-step flow

✍️

1 · Generate

Type a topic (or hit Run Cycle) and the agent researches trending developer news, then writes a full LinkedIn post with hashtags and a matching illustration.

🔎

2 · Review

Preview each draft, edit the text, swap the image, or reject it. Nothing goes out without your say-so — you're always in control.

🚀

3 · Publish

Publish now, or schedule for later. At the scheduled time the post goes live on your LinkedIn automatically — image and all.

What you get

🤖

Trend-aware writing

Posts are grounded in real, current developer news (Hacker News, InfoQ, GitHub, dev.to and more) — never generic filler. An LLM keeps only topics relevant to a technical audience.

🎨

Auto visuals

Every post gets a clean, professional illustration generated to match the topic — attached natively when it publishes to LinkedIn.

🗣️

Your brand voice

Add examples of posts you like under History and the agent learns your tone, emoji use, and spacing — so drafts sound like you.

⏰

Set-and-forget scheduling

Schedule posts for any date and time. The agent keeps running and publishes them at the exact moment — even while you're offline.

Good to know

🔒 Where do my posts go?

Only to your LinkedIn account — the one you signed in with. Each user's posts, drafts, and data are completely private to them.

✅ Do I approve every post?

Yes. Drafts sit in Drafts until you approve or schedule them. Nothing is posted automatically without you scheduling it.

🔁 Can I edit a draft?

Absolutely — open any draft's Preview to edit the body, change hashtags, or replace the image before it goes out.

🔗 How is my LinkedIn connected?

Through LinkedIn's official OAuth. You grant permission to post on your behalf; we never see your password, and you can revoke access from LinkedIn anytime.

Run your own PostAgent (post to your own account)

🔐

Why you need your own instance

LinkedIn only lets an app post on behalf of its owner and approved team members until the app passes LinkedIn's review for the "Share on LinkedIn" product. So on this shared instance, only the operator can publish. To have PostAgent post to your account, deploy your own copy with your own LinkedIn app — it's free and takes ~20 minutes. Every step is below.

🧰

Before you start — free accounts you'll need

  • GitHub — to fork the code · github.com/signup
  • MongoDB Atlas (free M0 database) · mongodb.com/cloud/atlas
  • Google Gemini API (free, writes the posts) · aistudio.google.com/apikey
  • LinkedIn Developer app (your posting app) · linkedin.com/developers/apps
  • Render (free hosting) · render.com
  • UptimeRobot (free, keeps it awake) · uptimerobot.com
1️⃣

Fork the code

Open github.com/himanshu60/PostAgent and click Fork (top-right) to copy it to your own GitHub. That's the repo Render will deploy. To run it locally instead: 

git clone https://github.com/<you>/PostAgent.git
cd PostAgent
cp .env.example .env   # fill in the values from the table below
go run ./cmd/agent -serve   # http://localhost:8081
2️⃣

MongoDB Atlas (database)

  1. Create a free M0 cluster.
  2. Database Access → add a user + password.
  3. Network Access → add 0.0.0.0/0 (allow anywhere).
  4. Connect → Drivers → copy the connection string. That's your MONGO_URI.
3️⃣

Gemini API key

Go to aistudio.google.com/apikey → Create API key → copy it. That's your GEMINI_API_KEY. (Keep images on Pollinations — it's free and needs no key. Gemini image generation needs paid billing.)

4️⃣

LinkedIn app (your posting app)

  1. Create an app at linkedin.com/developers/apps.
  2. Products → add "Sign In with LinkedIn using OpenID Connect" and "Share on LinkedIn".
  3. Auth tab → copy Client ID and Client Secret.
  4. Auth → Authorized redirect URLs → add your deployed URL's callback (fill this in after step 5):
    https://<your-service>.onrender.com/auth/callback
    and for local testing: http://localhost:8081/auth/callback
5️⃣

Deploy on Render (free)

  1. dashboard.render.com → New → Web Service.
  2. Connect your forked PostAgent repo (or use Public Git Repository and paste its URL).
  3. Render auto-detects the Dockerfile — keep defaults. Instance type: Free.
  4. Add the environment variables from the table below.
  5. Create Web Service. When live, copy your URL and put its /auth/callback back into the LinkedIn app (step 4.4).
🔑

All environment variables

Required (the app won't work without these):

Variable What it's for / where to get it
MONGO_URIDatabase — the Atlas connection string (step 2)
GEMINI_API_KEYWrites the posts — from Google AI Studio (step 3)
LINKEDIN_CLIENT_IDYour LinkedIn app → Auth (step 4)
LINKEDIN_CLIENT_SECRETYour LinkedIn app → Auth (step 4)

Recommended — copy these exact demo values to start:

LLM_PROVIDER=gemini
LLM_MODEL=gemini-2.5-flash
GEMINI_MODEL=gemini-2.5-flash
IMAGE_PROVIDER=pollinations
LINKEDIN_API_VERSION=202606
MONGO_DB=linkedin_agent
AGENT_SCHEDULE=CRON_TZ=Asia/Kolkata 0 0 9 * * *
AGENT_PUBLISH_DAYS=Mon,Wed,Fri
AGENT_TOPICS_COUNT=5
BRAND_VOICE_TONE=professional
BRAND_VOICE_MAX_EMOJI=3
BRAND_VOICE_MIN_LINE_BREAKS=3
LOG_LEVEL=info

Optional (leave unset unless you need them):

LLM_FALLBACK_PROVIDER / OPENROUTER_API_KEYBackup LLM if Gemini hits its quota (openrouter.ai)
NEWSAPI_KEYExtra trending-topic source (newsapi.org)
OPENAI_API_KEYOnly if IMAGE_PROVIDER=openai
PORTRender sets this automatically — do not add it
⚠️ Do not set LINKEDIN_ACCESS_TOKEN, LINKEDIN_REFRESH_TOKEN, or LINKEDIN_PERSON_ID — these are captured automatically when you sign in with LinkedIn.
6️⃣

Keep it awake (so posts publish on time)

Render's free tier sleeps after 15 minutes of no traffic, so scheduled posts would go out late. Fix it free: at uptimerobot.com → Add New Monitor → HTTP(s) → your Render URL → interval 5 minutes. Now the scheduler runs 24/7 and posts publish exactly on time.

7️⃣

Sign in and go

Open your Render URL → Sign in with LinkedIn → authorize. You're in your own private workspace, posting to your own account. Type a topic → Generate Posts, or let the daily auto-generate create and schedule posts for you.
